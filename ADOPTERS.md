# Adopters

A place for teams and individuals to share how they use proactive-gate in real deployments.

The list starts empty. Add an entry only through a pull request from the person or team using the project.

## Format

Each entry should include a name, a link, one sentence describing what proactive-gate decides for you, and an optional channel:

- **Name** ([link](https://example.com)): One sentence on what proactive-gate decides for us. Optional channel: [channel](https://example.com/channel).
